    五、数的编码对照表


    ┌──────┬────────────────┬────────────────────────┬──────────┬────────────────┐
    │ 类型 │ 正数表示       │ 负数表示               │ 0 的表示 │ 用途           │
    ├──────┼────────────────┼────────────────────────┼──────────┼────────────────┤
    │ 原码 │ 0xxxxxxx       │ 1xxxxxxx               │ ±0 两种  │ 直观表示       │
    │ 反码 │ 同原码         │ 符号位不变，数值位取反 │ ±0 两种  │ 过渡编码       │
    │ 补码 │ 同原码         │ 反码 +1                │ 唯一 0   │ 计算机内部运算 │

    示例（8 位二进制）：

     1 +5: 原码=00000101  反码=00000101  补码=00000101
     2 -5: 原码=10000101  反码=11111010  补码=11111011

    ┌──────────┬─────────────────────────────┬──────────┬──────────┬───────────┐

    ├──────────┼─────────────────────────────┼──────────┼──────────┼───────────┤
    │ 奇偶校验 │ 添加 1 位使 1 的个数为奇/偶 │ 1 位     │ 无       │ 内存校验  │
    │ 海明码   │ 多重奇偶校验                │ 多位     │ 1 位     │ 内存 ECC  │

     1         2^r ≥ k + r + 1
     2         
     3         r = 校验位个数
     4         k = 数据位个数

    七、Cache 映射方式对比


    ┌────────────┬──────────────────────┬──────────┬──────────────┬────────┐
    │ 映射方式   │ 原理                 │ 优点     │ 缺点         │ 冲突率 │
    ├────────────┼──────────────────────┼──────────┼──────────────┼────────┤
    │ 直接映射   │ 主存块→固定 Cache 行 │ 简单、快 │ 冲突多       │ 高     │

    └────────────┴──────────────────────┴──────────┴──────────────┴────────┘


    直接映射公式：

     1 Cache 行号 = 主存块号 mod Cache 总行数

    十三、性能指标公式图

      1                     计算机性能指标
      2                          │
      3       ┌──────────────────┼──────────────────┐
      4       │                  │                  │
      5    时钟周期            CPI              MIPS
      6       │                  │                  │
      7   T = 1/f          每条指令          百万指令
      8       │              时钟数            /秒
      9       ▼                  ▼                  ▼
     10   ┌────────┐      ┌──────────┐      ┌──────────┐
     11   │ 频率 Hz │      │ 程序时钟 │      │  CPU 速度 │

     13   └────────┘      └──────────┘      └──────────┘

    核心公式：

     1 CPU 执行时间 = 指令条数 × CPI × 时钟周期
     2            = (指令条数 × CPI) / 时钟频率
     3 
     4 Amdahl 定律:
     5 性能提升 = 1 / [(1-f) + f/S]
     6     f = 可加速部分比例
     7     S = 加速倍数
